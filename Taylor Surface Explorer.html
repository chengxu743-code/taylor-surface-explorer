How to read the picture

The red point

The selected point is p = (x₀,y₀). All derivatives and both approximations are recalculated there.

The orange plane

L(p+Δ) = f(p) + ∇f(p)ᵀΔ. It matches the function's height and slope at p, but has no curvature.

The violet patch

Q(p+Δ) = L(p+Δ) + ½ΔᵀH(p)Δ. It also matches the local curvature, so it usually stays close over a larger neighborhood.
